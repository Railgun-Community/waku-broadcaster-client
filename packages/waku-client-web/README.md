# @zeno/waku-client-web

Browser entrypoint for the Zeno Waku client: re-exports the shared transport core from `@zeno/waku-client-common` plus the Web platform bindings (LightNode factory and an IndexedDB replay-drop persistence). For dApps and web wallets.

See the [repository README](../../README.md) for the package map and development setup.
