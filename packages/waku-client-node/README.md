# @zeno/waku-client-node

Node.js entrypoint for the Zeno Waku client: re-exports the shared transport core from `@zeno/waku-client-common` plus the Node platform bindings (LightNode factory and a LevelDOWN-compatible replay-drop persistence). For servers, Electron, scripts, and the reference Solver.

See the [repository README](../../README.md) for the package map and development setup.
